# 自分専用・オフラインお買い物アプリ

Androidスマートフォンで使うことを中心にした、外部サービス不要のお買い物PWAです。商品、購入状態、価格、予算、設定は、このブラウザーの端末内にだけ保存されます。ログイン、広告、アクセス解析、外部APIは使用しません。

> 初回表示時とアプリ更新時だけは、ファイルを取得するためにインターネット接続が必要です。一度正しく読み込んで「ホーム画面に追加」した後は、機内モードでも利用できます。

## ファイル構成

```
shopping_pwa/
├─ index.html             # アプリ画面
├─ styles.css             # スマホ向け表示
├─ app.js                 # 商品・予算・バックアップの処理
├─ service-worker.js      # オフライン用キャッシュ
├─ manifest.webmanifest   # PWAの設定
├─ icon.svg               # アプリアイコン
└─ README.md              # この説明
```

## PCでの動作確認方法

Service Workerは `file:///` で直接HTMLを開くと動きません。VS CodeのLive Server拡張、またはローカルWebサーバーでフォルダーを開いてください。

例（Node.jsが入っている場合）:

```powershell
npx serve .
```

表示された `http://localhost:...` をChromeまたはEdgeで開きます。開発者ツールのデバイス表示でAndroid相当の幅も確認できます。保存データはブラウザーごとに異なります。

## GitHub Pagesでの公開手順

1. このフォルダーのファイルを、自分のGitHubリポジトリにコミットしてpushします（このアプリは個人データを含めずに公開してください）。
2. GitHubのリポジトリ画面で **Settings** → **Pages** を開きます。
3. **Deploy from a branch** を選び、公開するブランチと `/ (root)` を指定して保存します。
4. 表示されたURLをスマホで開きます。相対パスを使っているため、`/shopping_pwa/` のようなサブパスでも動きます。

この作業フォルダーには個人データを保存しないでください。買い物データはGitHubへ自動送信されませんが、バックアップJSONをリポジトリへ追加・公開しないよう注意してください。

## Androidスマホへの追加方法

1. Chromeで公開URLを開き、最初だけオンラインで画面を最後まで読み込みます。
2. Chrome右上のメニューから **ホーム画面に追加** または **アプリをインストール** を選びます。
3. 追加されたアイコンから起動します。

## 機内モードでの動作確認方法

1. オンラインのままアプリを一度開き、数秒待って必要なファイルをキャッシュします。
2. アプリを閉じ、機内モードをオンにします。
3. ホーム画面のアイコンから再度開きます。
4. 商品追加・編集・削除、購入チェック、予算計算、引き継ぎメモ、JSONバックアップを試します。

初回のキャッシュが完了する前、またはアプリ更新直後の初回利用では、通信が必要です。

## データ保存とバックアップの注意

- データは端末・ブラウザーごとのlocalStorageに保存されます。ブラウザーのサイトデータ消去、アプリ削除、端末初期化では失われる可能性があります。
- 大切な内容は設定画面の **JSONを書き出す** で定期的にバックアップしてください。
- 復元は同じ設定画面から行えます。復元すると、現在のアプリ内データはバックアップの内容で置き換わります。
- JSONには買い物内容や定型文が含まれます。メール添付、共有、GitHubへの追加を行う際は内容を確認してください。
